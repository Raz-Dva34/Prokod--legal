Политика конфиденциальности приложения «Прокод»

Дата вступления в силу: 7 сентября 2026 года

Версия: 1.0

Настоящая Политика описывает обработку сведений при использовании мобильного приложения «Прокод» (далее — «Приложение»).

Разработчик Приложения: Гацкан Максим Сергеевич.

1. Какие сведения обрабатываются

1.1. Локальные данные

Приложение сохраняет только на устройстве пользователя:

  • имя или псевдоним, указанные пользователем;
  • выбранные курсы, учебный прогресс, результаты тестов и ответы;
  • статистику занятий, достижения, избранные материалы и историю тренировочных собеседований;
  • тему оформления и другие настройки Приложения;
  • настройки и расписание локальных напоминаний;
  • время последнего показа рекламы, необходимое для ограничения частоты показов.

Разработчик не получает содержимое этих данных и не передаёт его на собственный сервер.

1.2. Рекламные данные

Приложение использует Yandex Mobile Ads SDK для показа межстраничной рекламы. При загрузке и показе рекламы ООО «ЯНДЕКС» может обрабатывать:

  • рекламный идентификатор устройства, если он доступен;
  • IP-адрес и сведения о сетевом соединении;
  • модель устройства, версию операционной системы, язык и технические характеристики;
  • идентификатор и версию Приложения;
  • сведения о загрузке, показе, закрытии рекламы и взаимодействии с объявлением;
  • диагностические данные и сведения, необходимые для предотвращения мошенничества.

Обработка этих данных Яндексом регулируется следующими документами:

  • Политика конфиденциальности Яндекса: https://yandex.ru/legal/confidential/
  • Условия использования Yandex Mobile Ads SDK: https://yandex.ru/legal/mobileads_sdk_agreement/

1.3. Уведомления

Приложение запрашивает системное разрешение на уведомления при включении пользователем напоминаний. Напоминания планируются локально на устройстве.

Приложение не получает и не передаёт разработчику push-токен устройства.

2. Для чего используются сведения

  • локальные данные — для работы курсов, тестов, статистики, достижений, настроек и напоминаний;
  • рекламные данные — для загрузки, показа и измерения рекламы, а также предотвращения рекламного мошенничества.

3. Передача данных

Разработчик не продаёт пользовательские данные.

Технические и рекламные сведения передаются ООО «ЯНДЕКС» через Yandex Mobile Ads SDK для работы рекламы.

Приложение не передаёт Яндексу имя пользователя, содержание ответов, результаты тестов или учебный прогресс.

4. Хранение и удаление

Локальные данные хранятся на устройстве до их удаления внутри Приложения, очистки данных Приложения в настройках устройства или удаления самого Приложения.

Разработчик не имеет удалённого доступа к локальным данным и не может удалить их с устройства пользователя.

Срок хранения рекламных данных определяется Яндексом согласно его Политике конфиденциальности.

5. Управление данными и разрешениями

Пользователь может:

  • удалить локальные данные средствами Приложения или операционной системы;
  • отключить напоминания внутри Приложения или запретить уведомления в настройках устройства;
  • ограничить персонализацию рекламы или сбросить рекламный идентификатор в настройках устройства, если такая возможность поддерживается операционной системой;
  • обратиться к Разработчику по адресу pechenkainc@gmail.com по вопросам работы Приложения с данными.

Вопросы об обработке рекламных данных Яндексом регулируются Политикой конфиденциальности Яндекса.

6. Внешние ресурсы

При переходе по ссылке или выборе поиска во внешнем сервисе открывается браузер.

Выбранный поисковый запрос или адрес страницы передаётся соответствующему внешнему сервису по инициативе пользователя. Дальнейшая обработка регулируется политикой этого сервиса.

7. Изменение Политики

Политика может быть обновлена при изменении функций Приложения или используемых внешних сервисов.

Актуальная редакция публикуется по тому же общедоступному адресу.
